# Amicale

L’appli d’un groupe (amicale, club, association) : membres, agenda, tâches, courses, événements, bulletins d’adhésion. Gratuite, sans publicité, sans compte ; les échanges du groupe sont chiffrés.

**Ouvrir l’appli : https://dam-cigogne.github.io/amicale/**

C’est le même code que [AgenDam](https://github.com/dam-cigogne/agenda) en mode « Amicale seule » : un groupe créé ou rejoint ici s’ouvre aussi dans AgenDam (onglet Groupe), avec les mêmes informations.

Ne pas modifier les fichiers ici à la main : ils sont copiés depuis AgenDam à chaque version.
